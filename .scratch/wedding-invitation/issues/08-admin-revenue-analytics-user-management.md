# 08: Admin: Revenue Analytics Dashboard & User Management Controls

**What to build:** Admin platform memiliki dashboard analitik untuk memantau pertumbuhan jumlah pengguna terdaftar, jumlah undangan yang dipublikasikan, total pendapatan dari transaksi Midtrans, serta tabel manajemen pengguna untuk menonaktifkan akun yang melanggar.

**Blocked by:** 06: Subscription: 4-Tier Plan Quota & Midtrans Snap Payment

**Status:** ready-for-agent

- [ ] Dashboard admin menampilkan ringkasan metrik utama: total pengguna terdaftar, total undangan aktif/terbit, dan total pendapatan (MRR).
- [ ] Grafik tren visual pendaftaran pengguna baru dan riwayat transaksi bulanan.
- [ ] Tabel manajemen pengguna dengan fitur pencarian, filter berdasarkan tier langganan dan status akun.
- [ ] Admin dapat menonaktifkan akun pengguna bermasalah; aksi deaktifasi otomatis mengubah status semua undangan milik pengguna tersebut menjadi tidak terbit (unpublish).
- [ ] Admin dapat melihat detail transaksi pembayaran Midtrans dan mengubah status secara manual jika terjadi kendala rekonsiliasi pembayaran.
